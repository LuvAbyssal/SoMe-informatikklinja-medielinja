# Kuben – 1MIP

Nettside som promoterer informatikklinja og medielinja på Kuben videregående skole, med lenker til linjenes sosiale medier.

Krav, valgt løsning og mappestruktur er beskrevet i [dokumentasjon.md](dokumentasjon.md).

**Er du elev?** Les [arbeidsflyt.md](arbeidsflyt.md) først. Der står det steg for steg hvordan du forker repoet, setter opp GitHub Pages, gjør endringer og lager en pull request.

## Kom i gang

1. Åpne mappen i VS Code.
2. Installer utvidelsen **Live Server**.
3. Høyreklikk på `index.html` og velg **Open with Live Server**.

Siden virker ikke hvis du dobbeltklikker på `index.html`. Les hvorfor i [dokumentasjon.md](dokumentasjon.md#viktig-å-vite).

## Hvor jobber jeg?

Hver seksjon har sin egen HTML-fil i `seksjoner/` og sin egen CSS-fil i `css/`. Jobb bare i filene til din seksjon. Felles stil for header og footer ligger i `css/felles.css`.
